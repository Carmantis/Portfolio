AI Code Assistant

Python application leveraging Large Language Models for automatic code documentation and test generation. Microservice architecture: FastAPI backend, Streamlit UI, and Ollama LLM service with Qwen2.5-Coder.

Architecture

Three-tier microservice setup: FastAPI backend (port 8001) receives code via REST API, Streamlit UI (port 8501) provides web interface, Ollama (port 11434) runs Qwen2.5-Coder locally with GPU acceleration. Docker Compose orchestration for easy deployment.

Features

  • Documentation: Automatic docstrings and inline comments.
  • Tests: Pytest-compatible unit tests ready to use.
  • Prompt Engineering: Optimized prompts with JSON-enforced output.
  • Error Handling: Robust parsing, timeouts, mock mode for testing.

Technologies

  • Backend: Python 3.11+, FastAPI, Pydantic, httpx, Uvicorn
  • Frontend: Streamlit, custom CSS styling
  • AI/ML: Ollama, Qwen2.5-Coder (3B/14B parameters)
  • Infrastructure: Docker, Docker Compose, uv package manager

Workflow

User inputs Python code → UI sends POST to backend → Backend constructs prompts and calls Ollama API → LLM generates documented code and tests in JSON → UI displays results in tabs with download options.

Future

Multi-provider support (OpenAI, Anthropic), RAG for context-aware analysis, caching layer, batch processing for large codebases, code quality metrics.
