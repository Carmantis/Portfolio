Deep Learning for Image Classification

This project focused on building a computer vision pipeline that combined segmentation and classification to improve prediction accuracy. The workflow was designed to isolate relevant regions in images before applying a state-of-the-art classifier, ensuring the model learned only the most meaningful features.

Key Accomplishments

  • Implemented segmentation with Segment Anything Model (SAM) to extract regions of interest.
  • Applied transfer learning with EfficientNet for high-accuracy classification.
  • Developed a custom dataset pipeline with PyTorch and torchvision transforms.
  • Tracked performance using validation accuracy and moving averages during training.

Tools & Technologies

  • Python, PyTorch, torchvision, Jupyter Notebook.
  • NumPy, Pandas for data handling.
  • Matplotlib for visualization.
  • Git for version control.

Challenges & Outcome

Integrating segmentation with classification required designing a multi-step pipeline and testing each component independently. The final solution achieved strong accuracy by focusing on the most relevant image regions and applying robust data augmentation.
