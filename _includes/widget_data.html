Data Management in Indoor Positioning

This project focused on developing a system infrastructure for collecting, processing, and analyzing indoor positioning data. The key goal was to enable efficient handling of historical location data and visualize it for decision-making purposes.

Key Accomplishments

  • Data preprocessing with Pandas, DuckDB, and SQL.
  • Visualizations via Seaborn, Matplotlib, and custom scripts.
  • Analytical models to correlate FMI weather with visits, monitor checkout utilization, and optimize layouts from cart speed & distance metrics.
  • Baseline predictive model using Random Forest.

Tools & Technologies

  • GitLab (milestones, issue boards), Streamlit, Jupyter.
  • Clockify for time tracking.
  • Python stack: Pandas, Seaborn, Scikit-learn.

Challenges & Outcome

Large datasets required careful query optimization and reduced data density. Scrum-based iterations helped mitigate bottlenecks. The dashboard provided actionable insights into customer behavior and operations.
