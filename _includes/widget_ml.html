Predictive Modeling with LSTM

End-to-end project with dbt + DuckDB + Streamlit, following a Medallion Architecture (Bronze/Silver/Gold). Focus: quarterly forecasting with a Keras LSTM.

Highlights

  • KNN-Imputer for missing data; MinMaxScaler for features; one-hot encodings for units & quarters.
  • LSTM model evaluation: MAE, RMSE, R².
  • Interactive Streamlit UI for historical vs predicted comparisons.

Outcome

Consistent transformations with dbt & DuckDB improved reliability. The LSTM provided robust forecasts; Streamlit UI enabled exploration and insight.
